## 🚀 About Me

DevOps Engineer focused on **Python automation, CI/CD, containerization, and cloud-native technologies**. I build automation frameworks, manage CI/CD infrastructure, and make software delivery faster, safer, and more observable.

I enjoy solving infrastructure problems, automating engineering processes, and building reliable systems. Currently deep-diving into **AWS, Terraform, Kubernetes, GitOps, and observability** — because a platform is only legendary when it survives production.

### 💼 What I do every day

- **CI/CD pipelines** — Jenkins, GitHub Actions, and build automation that keeps deploys green
- **Container orchestration** — Docker and Kubernetes for portable, scalable workloads
- **Infrastructure as Code** — Terraform and Ansible for repeatable, reviewable infrastructure
- **Cloud platforms** — AWS and Azure for services that scale without drama
- **Observability** — Grafana, Prometheus, and InfluxDB to keep the dashboard honest
- **Automation** — Python and Bash to eliminate manual work and reduce toil
- **Databases** — PostgreSQL, MySQL, MongoDB, and Couchbase when the stack demands data
- **Application delivery** — Django, Nginx, and reverse-proxy patterns for production traffic
